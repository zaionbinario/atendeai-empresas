# AtendeAI Empresas

Crie um sistema SaaS chamado AtendeAI, totalmente em português brasileiro.

O objetivo é oferecer atendimento automatizado com inteligência artificial para pequenas empresas e lojas.

Crie inicialmente um painel administrativo moderno, profissional e responsivo, com identidade visual verde e branca.

O painel deve conter:

1. Dashboard com resumo do atendimento.

2. Cadastro de empresas.

3. Cadastro de produtos, preços e descrições.

4. Configuração de horários de funcionamento.

5. Cadastro de perguntas frequentes e respostas.

6. Área para configurar as instruções do atendente virtual.

7. Simulador de conversa com aparência semelhante ao WhatsApp.

O sistema deve ter visual simples e intuitivo, adequado para pessoas sem conhecimento técnico.

IMPORTANTE:

Nesta primeira versão, crie somente a interface e as funcionalidades visuais com dados de demonstração. Não conecte APIs, pagamentos ou WhatsApp ainda.

Organize o projeto pensando em uma futura integração com Supabase e WhatsApp Business Platform.
